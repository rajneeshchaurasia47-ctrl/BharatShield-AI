# BharatShield AI — Sangyan Hackathon
Explainable investor-resilience prototype for scam and misinformation content.

## Run
pip install -r requirements.txt
streamlit run app.py

## Scope
Paste a financial message/claim/link → detect observable red flags → explain reasons → suggest safer next steps.

No stock tips, buy/sell/hold signals, price predictions, monetization funnel, OTP/SMS harvesting or personalized investment recommendations.
